# Hallintolain (434/2003) kommentaari

Kommentaari suomalaiseen säädökseen: **Hallintolaki 6.6.2003/434**. Kommentaari kattaa **89 pykälää** (1–71 §, mukaan lukien a–g-pykälät sekä voimaantulo- ja siirtymäsäännökset) **4 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, versio **20250541** (ajantasaistettu **27.6.2025**, viimeisin huomioitu muutos L 27.6.2025/541, voimaan 1.1.2026).

## Sisällysluettelo

Ks. [INDEX.md](INDEX.md). Menetelmän kuvaus on tiedostossa [00-johdanto.md](00-johdanto.md).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti), ilman kaupallisia oikeudellisia tietokantoja. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
